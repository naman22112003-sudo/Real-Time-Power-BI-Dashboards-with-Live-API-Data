
## 🚀 Real-Time Power BI Dashboard with Live API Data

This project focuses on building a **real-time interactive Power BI dashboard** by integrating **live API data** to deliver continuously updated insights for data-driven decision-making.

### 📌 Project Overview

* Integrated live APIs using Python for efficient data extraction and cleaning
* Automated the complete data pipeline for real-time updates
* Built dynamic Power BI dashboards to monitor KPIs and key indicators
* Enabled end-to-end workflow from API ingestion to business intelligence visualization

### 📊 Key Insights Generated

* Regional Health Spending Patterns
* GDP per Capita vs Economic Growth
* Poverty Reduction Trends
* Trade and Economic Development
* Correlation Between Health Indicators
* Internet Penetration and Employment
* Healthcare Investment Disparities
* Technology Impact on Socioeconomic Growth

### 🛠️ Tools & Technologies

* Power BI
* Python
* SQL
* API Integration
* Power Query
* Data Visualization
* KPI Analysis
* Business Intelligence

### 🎯 Learning Outcomes

This project enhanced my understanding of **real-time analytics**, **automated data pipelines**, and **modern BI reporting**, bridging raw API data with actionable business insights.
